# AgroNexo Demo

Demostración funcional y responsive para **Finca La Libertad** y **VillaYolsa**, con datos completamente ficticios.

Incluye módulos productivos, inventario, finanzas, agenda, alertas, roles y agente conversacional demostrativo.

## Ejecutar

```bash
npm start
```

Abrir `http://127.0.0.1:4173`.
